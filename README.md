# Hệ thống Quản lý Nhân sự (HR Management System)

## Thông tin sinh viên
- **Họ và tên:** Trần Minh Tâm
- **MSSV:** 239714
- **Lớp:** DH23TIN10

## Giới thiệu hệ thống
Hệ thống quản lý nhân sự trên nền tảng đám mây. Hỗ trợ các chức năng xem, thêm, sửa, xóa và tìm kiếm thông tin nhân viên.

## Công nghệ sử dụng
- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** MongoDB Atlas
- **Docker & Docker Hub**
- **Deployment:** Render

## Hướng dẫn chạy môi trường phát triển (Local)
1. Backend: `cd backend && npm install && npm run dev`
2. Frontend: `cd frontend && npm install && npm start`
